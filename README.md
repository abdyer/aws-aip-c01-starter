# AWS Generative AI Developer Professional Exam Prep

Claude-powered exam prep for the [AWS Generative AI Developer Professional certification](https://aws.amazon.com/certification/certified-generative-ai-developer-professional/). This repository contains skills to help you prepare for the exam.

## Skills

### `/practice-session`

The primary skill. Generate 10 practice questions using the exam guide and [AWS Knowledge MCP server](https://awslabs.github.io/mcp/servers/aws-knowledge-mcp-server). Questions are written to the `questions` directory. Session notes are written to the `sessions` directory.

### `/weekly-summary`

Generate a weekly summary of your practice sessions. This skill will analyze your performance and provide insights into areas where you need improvement. Weekly summaries are written to the `summary` directory.
